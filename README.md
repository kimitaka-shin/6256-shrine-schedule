# 六二五六珈琲｜神社出店スケジュール

高円寺氷川神社での出店日程を、月間カレンダーと月内一覧で表示する独立した静的ページです。
既存の神社出店アプリのソースコード・データ・公開先には接続しません。

## ファイル構成

- `index.html`：ページ本体
- `styles.css`：デザイン・スマートフォン対応
- `script.js`：カレンダー、一覧、Google Apps Scriptからの読み込み
- `config.js`：スプレッドシート連携URLの設定箇所
- `Code.gs`：Google Apps Script側の読み取り専用API
- `assets/koenji-hikawa-shrine.jpg`：高円寺氷川神社の写真
- `render.yaml`：Render Static Site用設定

## 1. Googleスプレッドシートを用意

1. 同梱の `6256_shrine_schedule_template.xlsx` をGoogle Driveにアップロードします。
2. ファイルをGoogleスプレッドシートで開き、「Googleスプレッドシートとして保存」します。
3. `出店予定` シートに、2行目から日程を入力します。1行につき1日程です。
4. 日付は `yyyy-mm-dd`、時刻は `9:30` のように入力してください。
5. 営業状況はプルダウンから「出店予定」「中止」「変更あり」を選んでください。

列の意味：

| 列 | 項目 | 入力例 |
|---|---|---|
| A | 日付 | 2026-11-15 |
| B | 営業状況 | 出店予定 / 中止 / 変更あり |
| C | 開始時間 | 9:30 |
| D | 終了時間 | 16:30 |
| E | 最終受付 | 16:00 |
| F | 場所 | 高円寺氷川神社 |
| G | お知らせ | 雨天時は中止となる場合があります |

日程がない場合は行を追加しなくて大丈夫です。ページに「現在、次回の出店日程を調整中です。」と表示されます。

## 2. Google Apps Scriptを設定

1. Googleスプレッドシートを開き、メニューの「拡張機能」→「Apps Script」を選びます。
2. エディタ内のサンプルコードを削除し、同梱の `Code.gs` の内容を貼り付けて保存します。
3. 右上の「デプロイ」→「新しいデプロイ」を選びます。
4. 種類（歯車アイコン）で「ウェブアプリ」を選択します。
5. 次の設定でデプロイします。
   - 次のユーザーとして実行：自分
   - アクセスできるユーザー：全員
6. 表示されたウェブアプリURL（末尾が `/exec` のURL）をコピーします。

このAPIは出店日程を読むだけです。スプレッドシートへの書き込み機能はありません。公開ページに日程を表示するため、入力した日付・営業時間・お知らせは一般公開されます。個人情報は入力しないでください。

## 3. ページにAPI URLを設定

`config.js` には今回のウェブアプリURLを設定済みです。

```js
window.SCHEDULE_API_URL = "https://script.google.com/macros/s/ここにデプロイID/exec";
```

保存後、サイトを再公開します。

## 4. Renderに独立したStatic Siteとして公開

**既存の神社出店アプリのRenderサービスやGitHubリポジトリは変更しないでください。** このフォルダ専用の新しいGitHubリポジトリを作り、新規Static Siteとして公開します。

1. GitHubで新しい空のリポジトリを作成します（例：`6256-shrine-schedule`）。
2. このフォルダ内のファイルと `assets` フォルダを、新しいリポジトリのルートにアップロードします。
3. Renderで「New」→「Static Site」を選び、新しいリポジトリを接続します。
4. Publish Directory は `.` を指定します（`render.yaml` を使う場合は自動設定されます）。
5. デプロイ完了後に発行されるURLを開き、カレンダーが表示されることを確認します。

**注意：** 既存の抽出体験アプリと同じリポジトリへ追加する構成にはしていません。別リポジトリ・別Static Siteにすることで、アプリ側のファイルや設定を触らずに運用できます。

## 5. LINEリッチメニューに追加

公開URLを、リッチメニューの3つ目のエリア「神社出店スケジュール」に設定します。既存の「淹れ方を見る」のURLを置き換える場合も、抽出体験アプリ側のURLやファイルは変更しません。

## 運用

- 日程の追加・変更・中止はGoogleスプレッドシートの `出店予定` シートを編集します。
- 通常、ページは読み込み時に最新の日程を取得します。
- 既に開いているページには反映されないため、更新を確認するときはページを再読み込みします。
- 営業時間や最終受付が日によって異なる場合は、その日の行に入力してください。
